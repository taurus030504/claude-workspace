# 앨범 표지 생성 지침 (GPT 이미지 생성용, 그래픽 스타일)

쓰는 법
1. 가수별 "공통 지침"을 먼저 붙여 넣는다. 이은호 표지 4장과 김서진 표지 2장은 대화를 나눠서 만든다. 한 대화에서 섞으면 두 사람 스타일이 비슷해진다.
2. 그다음 앨범 지침을 하나씩 붙여 넣는다. 앨범마다 2~3장을 받아 고른다.
3. 받은 그림은 `02_웹앱/원본/앨범표지/` 폴더에 앨범 이름으로 저장한다. (예: `파란선.png`)
4. 제목 글자는 그림에 넣지 않는다. 글자는 위키와 가사 영상에서 Pretendard로 얹는다. 대신 글자가 들어갈 빈자리는 앨범마다 지정해 두었다.

앨범 콘셉트는 교사 검토용 초안이다. 바꾸고 싶으면 "장면" 부분만 고쳐 쓰면 된다.

## 이은호 공통 지침 (리소그래프 인쇄)

```
지금부터 가상의 한국 싱어송라이터 '이은호'의 앨범 표지를 그래픽으로 만들 거야. 아래 규칙을 이 대화의 모든 그림에 똑같이 적용해 줘.

스타일: 리소그래프(리소 인쇄)로 찍은 2도 또는 3도 포스터.
- 잉크는 앨범마다 내가 정해 주는 2~3색만 쓴다. 그 밖의 색은 종이색뿐.
- 색이 겹치는 곳은 잉크가 겹쳐 인쇄된 색이 나온다. (예: 주황 위에 파랑이 겹치면 어두운 갈색)
- 판이 살짝 어긋나서 색 경계가 1~2mm 밀려 있다.
- 면은 균일하지 않다. 잉크가 덜 묻은 곳, 얼룩, 거친 입자가 보인다.
- 종이는 약간 누런 미색 갱지. 종이 결이 보인다.
- 형태는 단순한 도형과 굵은 면 위주. 가는 선과 세밀한 묘사는 넣지 않는다.

공통 규칙:
- 정사각형 1:1.
- 사람 얼굴 금지. 사람이 필요하면 아주 작은 실루엣만.
- 글자, 숫자, 로고, 기호를 하나도 넣지 않는다.
- 피해야 할 것: 매끈한 그라데이션, 반짝이는 광택, 3D 입체감, 좌우 대칭, 정중앙 배치, 벡터처럼 완벽한 가장자리, 귀여운 캐릭터풍 일러스트.
- 내가 알려 준 장면만 그리고, 설명에 없는 요소를 보태지 마.
```

### 1. 《파란선》 2023, 데뷔 디지털 싱글

```
앨범: 파란선 (데뷔 싱글)
잉크: 주황, 바랜 파랑
장면: 화면 대부분이 주황 면. 그 위를 굵기가 고르지 않은 파란 선 하나가 왼쪽 아래에서 오른쪽 위로 비스듬히 가로지른다. 선은 손으로 그은 것처럼 중간에 조금 끊기고 흔들린다. 선이 주황과 겹치는 곳만 어두운 색이 된다.
글자 자리: 오른쪽 아래 구석을 비워 둔다.
```

### 2. 《반경》 2024, 미니 1집

```
앨범: 반경 (미니 1집)
잉크: 황토, 짙은 남색
장면: 짙은 남색 바탕에 황토색 원 하나. 원은 화면 왼쪽 위에 치우쳐 있고 일부가 화면 밖으로 잘린다. 원 둘레에 조금씩 커지는 동심원 테두리 두세 개가 흐리게 퍼진다. 오른쪽 아래 넓은 면은 남색으로 비워 둔다.
글자 자리: 오른쪽 아래 남색 면.
```

### 3. 《낮게, 오래》 2025, 디지털 싱글

```
앨범: 낮게, 오래 (디지털 싱글)
잉크: 살구색, 고동색
장면: 화면 아래 5분의 1만 고동색 땅. 그 위는 전부 살구색 하늘. 땅 위 오른쪽에 아주 작은 사람 실루엣 하나가 걸어간다. 실루엣에서 왼쪽으로 길게 그림자가 뻗는다. 하늘은 아무것도 없이 넓게.
글자 자리: 왼쪽 위 하늘.
```

### 4. 《두 번째 창》 2025, 미니 2집 타이틀

```
앨범: 두 번째 창 (미니 2집)
잉크: 주황, 회청색, 노랑 (3도)
장면: 낡은 2층 주택 정면을 단순한 사각형 면으로만 표현. 회청색 벽에 창문 두 개가 나란히 있다. 첫 번째 창은 어둡고, 두 번째 창만 노랗게 불이 켜져 있다. 창 안에 커튼을 뜻하는 주황색 세로 띠 하나. 집 전체가 화면 오른쪽으로 치우치고 일부가 잘린다.
글자 자리: 왼쪽 세로 여백.
```

## 김서진 공통 지침 (종이 콜라주와 망점 인쇄)

```
지금부터 가상의 한국 싱어송라이터 '김서진'의 앨범 표지를 그래픽으로 만들 거야. 아래 규칙을 이 대화의 모든 그림에 똑같이 적용해 줘.

스타일: 색종이를 가위로 오려 붙인 콜라주를 스캔한 것.
- 종이 조각의 가장자리는 손으로 오린 것처럼 조금 삐뚤다. 일부는 손으로 찢은 결이 보인다.
- 종이끼리 겹친 곳에 아주 얇은 그림자가 생긴다.
- 조각 중 하나는 신문 인쇄처럼 굵은 망점(하프톤 도트)으로 채운다.
- 반투명 마스킹 테이프 한 조각이 어딘가에 붙어 있다.
- 색은 앨범마다 내가 정해 주는 2~3색 종이와 흰 바탕 종이만.
- 형태는 단순한 도형 위주. 세밀한 묘사는 넣지 않는다.

공통 규칙:
- 정사각형 1:1.
- 사람 얼굴 금지. 사람이 필요하면 손이나 뒷모습 실루엣만.
- 글자, 숫자, 로고, 기호를 하나도 넣지 않는다.
- 피해야 할 것: 매끈한 그라데이션, 반짝이는 광택, 3D 입체감, 좌우 대칭, 정중앙 배치, 벡터처럼 완벽한 가장자리, 귀여운 캐릭터풍 일러스트.
- 내가 알려 준 장면만 그리고, 설명에 없는 요소를 보태지 마.
```

### 5. 《초점》 2025.12, 데뷔 디지털 싱글

```
앨범: 초점 (데뷔 싱글)
종이: 남색, 청록, 흰색
장면: 남색 바탕 종이 위에 흰 종이로 오린 큰 원 하나(렌즈). 원 안쪽은 청록 망점으로 채워져 있는데, 원의 한쪽 부분만 망점이 촘촘하고 또렷하고 나머지는 망점이 흩어져 흐릿하다. 원은 화면 왼쪽 아래에 치우쳐 있고, 원 가장자리를 마스킹 테이프가 가로지른다.
글자 자리: 오른쪽 위 남색 면.
```

```
앨범: 천천히 말해 (디지털 싱글)
종이: 회청색, 연한 하늘색, 흰색

글자 자리: 위쪽 절반의 흰 여백.
```

## 받은 그림 고르는 기준 (AI 느낌 거르기)

하나라도 걸리면 다시 생성한다.
- 글자나 글자 비슷한 무늬가 생겼다.
- 정해 준 색 말고 다른 색이 섞였다. 특히 은은한 그라데이션.
- 가장자리가 너무 깨끗하다. 인쇄 어긋남, 얼룩, 종이 결이 안 보인다.
- 형태가 너무 많고 세밀하다. 장면 설명에 없는 소품이 들어왔다.
- 정중앙에 놓였거나 좌우가 거의 대칭이다.
- 글자 자리로 정한 곳이 채워져 있다.

재생성할 때 붙이는 말: "더 거칠게. 인쇄가 덜 깨끗하게. 형태는 더 적게, 여백은 더 넓게."
