# 앨범 표지 생성 지침 (GPT 이미지 생성용)

쓰는 법
1. 아래 "공통 지침"을 먼저 붙여 넣는다.
2. 그다음 앨범 하나씩 "앨범 지침"을 붙여 넣어 생성한다. 앨범마다 2~3장을 받아 가장 사진 같은 것을 고른다.
3. 받은 그림은 `02_웹앱/원본/앨범표지/` 폴더에 앨범 이름으로 저장한다. (예: `파란선.png`)
4. 제목 글자는 그림에 넣지 않는다. 글자는 위키와 가사 영상에서 Pretendard로 얹는다.

앨범 콘셉트는 교사 검토용 초안이다. 바꾸고 싶으면 "장면" 부분만 고쳐 쓰면 된다.

---

## 공통 지침 (맨 처음 한 번 붙여 넣기)

```
지금부터 가상의 한국 싱어송라이터 앨범 표지를 만들 거야. 아래 규칙을 모든 그림에 똑같이 적용해 줘.

- 정사각형 1:1, 1024×1024 이상.
- 실제로 찍은 사진처럼 보여야 해. 일러스트, 3D, 그래픽 디자인 느낌은 안 돼.
- 35mm 필름 카메라로 찍은 스냅사진 느낌. 약한 필름 그레인, 살짝 흐린 초점, 완벽하지 않은 구도.
- 사람 얼굴은 절대 넣지 않는다. 사람이 필요하면 뒷모습, 손, 그림자만.
- 글자, 로고, 워터마크, 기호를 하나도 넣지 않는다. 제목은 내가 나중에 따로 얹을 거야.
- 색은 과하게 선명하지 않게. 채도를 낮추고 빛은 자연광만.
- 피해야 할 것: 좌우 대칭 구도, 네온 불빛, 렌즈 플레어, 지나치게 매끈한 표면, 빈틈없이 꽉 찬 디테일, 몽환적인 보라색 하늘, 한가운데 놓인 사물.
- 소품과 장소는 한국의 평범한 동네와 집. 2010년대 후반 느낌.
- 각 앨범마다 내가 장면을 알려 줄게. 장면 설명대로만 찍고, 설명에 없는 요소를 보태지 마.
```

## 이은호 (주황과 황토 계열, 따뜻한 오후 빛)

### 1. 《파란선》 2023, 데뷔 디지털 싱글

```
앨범: 파란선 (이은호 데뷔 싱글, 2023)
장면: 오래된 아파트 복도의 흰 벽. 벽 아래쪽에 페인트로 그어 놓은 가느다란 파란 선이 복도를 따라 멀리 이어진다. 오후 햇빛이 창문 틀 모양으로 벽에 떨어져 있다. 사람 없음.
색: 벽은 따뜻한 미색, 선만 바랜 파란색.
구도: 선이 왼쪽 아래에서 오른쪽 위로 비스듬히 지나가게. 카메라를 조금 기울여서.
```

### 2. 《반경》 2024, 미니 1집

```
앨범: 반경 (이은호 미니 1집, 2024)
장면: 밤에 골목 가로등 하나가 바닥에 둥근 빛을 만든다. 빛의 가장자리가 그림의 주인공. 빛 안쪽 바닥에 자전거 바퀴 자국이나 물 자국이 살짝 보인다. 사람 없음.
색: 전체는 어두운 갈색과 검정, 가로등 빛만 주황빛 노랑.
구도: 둥근 빛을 화면 한쪽에 치우치게 두고 반대쪽은 어둡게 비운다.
```

### 3. 《낮게, 오래》 2025, 디지털 싱글

```
앨범: 낮게, 오래 (이은호 디지털 싱글, 2025)
장면: 해 질 무렵 한강 둔치처럼 넓고 낮은 땅. 지평선이 화면 아래쪽 5분의 1에 있고 나머지는 흐린 하늘. 멀리 작은 사람 하나가 뒷모습으로 걸어간다. 긴 그림자.
색: 하늘은 탁한 살구색에서 회색으로, 땅은 어두운 황토색.
구도: 아주 낮은 카메라 높이. 긴 노출을 준 것처럼 구름이 살짝 흘러 있다.
```

### 4. 《두 번째 창》 2025, 미니 2집 타이틀

```
앨범: 두 번째 창 (이은호 미니 2집, 2025)
장면: 오래된 주택의 작은 방 안. 벽에 창문 모양의 햇빛이 떨어져 있고, 창문 그림자 안에 커튼이 흔들린 흔적이 흐릿하게 남아 있다. 방은 거의 비어 있고 바닥에 이사 상자 하나. 사람 없음.
색: 미색 벽, 햇빛은 연한 노랑, 그림자는 따뜻한 회갈색.
구도: 창문 빛이 화면 오른쪽에 치우치게. 왼쪽 벽은 비워 둔다.
```

## 김서진 (청록과 남색 계열, 흐린 날 실내 빛)

### 5. 《초점》 2025.12, 데뷔 디지털 싱글

```
앨범: 초점 (김서진 데뷔 싱글, 2025)
장면: 집 안 식탁 위. 초점이 맞지 않아 전부 흐릿한데, 식탁 가장자리에 놓인 낡은 필름 카메라 하나만 또렷하다. 뒤쪽으로 창가에서 들어오는 흐린 낮빛과 둥근 빛망울.
색: 남색과 청록이 섞인 어두운 톤, 카메라 몸체는 검정과 은색.
구도: 카메라를 화면 아래 왼쪽에, 나머지 3분의 2는 흐린 배경.
```

### 6. 《천천히 말해》 2026, 디지털 싱글

```
앨범: 천천히 말해 (김서진 디지털 싱글, 2026)
장면: 흐린 아침 창가. 창틀에 놓인 녹음기 하나와 꼬인 이어폰 줄. 창밖은 안개로 희게 날아가 있다. 창문 유리에 물방울이 조금 맺혀 있다. 사람 없음.
색: 흰색과 회청색이 대부분, 녹음기만 어두운 색.
구도: 창틀이 화면을 가로로 나누고, 사물은 한쪽 구석에 작게.
```

## 받은 그림 고르는 기준 (AI 느낌 거르기)

하나라도 걸리면 다시 생성한다.
- 글자나 글자 비슷한 무늬가 생겼다.
- 사물이 화면 정중앙에 놓였거나 좌우가 거의 대칭이다.
- 표면이 지나치게 매끈하고 먼지, 얼룩, 흠집이 하나도 없다.
- 빛이 여러 방향에서 동시에 온다.
- 색이 너무 선명하거나 보라색, 분홍색 하늘이 나왔다.
- 사물의 세부가 녹은 것처럼 뭉개졌다. (카메라 다이얼, 창틀 모서리, 이어폰 줄)

재생성할 때 붙이는 말: "더 평범한 스냅사진처럼. 덜 예쁘게, 덜 정돈되게. 빛은 한 방향에서만."

## 저장 뒤 할 일 (제가 함)

- 그림을 600×600 webp로 줄여서 위키와 가사 영상 플레이어에 넣는다. 한 장에 40KB 안쪽.
- 제목과 이름을 Pretendard로 얹는다. 위치는 앨범마다 다르게 (왼쪽 아래, 오른쪽 위 등) 해서 한 사람이 다 만든 티를 뺀다.
- 지금 코드로 그린 SVG 표지는 그림이 들어오는 대로 지운다.
