2. `python3 02_웹앱/도구/아티팩트용_변환.py` 로 사본을 다시 만든다. (`python3 … 문영TV` 처럼 이름을 주면 하나만)

## 문영TV 연결 해제 (2026-10-09)

- 교사 결정으로 위키의 문영TV 링크를 모두 뺐다(각주의 라디오 출연분, 해당 장면, 음반 표의 가사 영상 등). `site.videoBase`도 지웠다.
- 문영TV 페이지 자체는 지우지 않았다. 위의 영상 id 표는 기록으로만 남긴다.
- 출신 아티스트의 가상 발매곡은 JL컴퍼니 문서 "발매 음반" 표와 남궁현 "참여 작품" 표에 있다. 곡 제목은 링크 없는 글자.

## 가상 SNS 연결 (2026-10-09)

- 위키의 `@계정` 링크는 모두 가상 SNS로 간다. 주소는 위키 데이터의 `site.snsBase` 하나만 고치면 된다(지금은 비어 있어 누르면 "SNS 화면은 준비되면 연결됩니다." 안내만 뜬다).
- 주소 규칙 (SNS 화면을 만들 때 이 해시를 읽어 화면을 열면 된다)
  - 계정 화면: `snsBase#/@계정` 예) `#/@seojin_official`
  - 게시물 하나: `snsBase#/@계정/글번호` 예) `#/@seojin_official/20241119`
- 위키에 있는 계정 링크
  - `@seojin_official`: 김서진 정보상자 사진 아이콘, SNS 칸, 여담. 사건 사고의 반론 각주는 게시물 `20241119`(연습 노트, `02_웹앱/원본/가사_자료_초안.md` 8번)로 간다.
  - `@e_euno_official`: 이은호 정보상자 사진 아이콘, SNS 칸, 여담.
- 공식 홈, 공식 영상 채널, 팬 소통 계정, JL COMPANY 공식 채널, 학교 홈페이지는 계정 이름이 없어 아직 연결하지 않았다. 계정 이름을 정하면 `{{외부:@계정}}` 또는 `{{링크아이콘:사진|@계정}}`으로 바꾸면 된다.
- 게임 웹앱에 합칠 때는 `window.MOONYOUNG_SNS_BASE`로 주소를 넘기거나 `window.MOONYOUNG_OPEN_SNS(계정, 글번호)` 함수를 두면 새 탭 대신 그 함수가 연다.

## 메모장 (2026-10-09)

- 특수 기능 > 메모장. 화면 오른쪽 아래(휴대폰은 아래쪽 절반)에 떠 있는 창이라 문서를 읽으면서 쓸 수 있다. 접기, 닫기 가능.
- 쓰는 즉시 이 브라우저(localStorage `moonyoung-wiki-memo`)에 저장된다. 다른 기기나 교사 화면으로는 가지 않는다.
- [출처 넣기]: 문서에서 글을 드래그한 뒤 누르면 `"그 글" (문서 이름, n턴)`이 들어간다. 선택이 없으면 `[문서 이름, n턴]`만 들어간다.
- [지우기]는 두 번 눌러야 지워진다(3초 안에 '정말 지우기').
