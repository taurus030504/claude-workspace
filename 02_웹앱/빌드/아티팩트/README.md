- 이 폴더의 `인물위키.html`은 게시용 사본이다. 직접 고치지 않는다.

## 수정 후 다시 게시하기

1. `02_웹앱/빌드/인물위키.html`을 고친다.
2. `python3 02_웹앱/도구/아티팩트용_변환.py` 로 사본을 다시 만든다.
3. 사본을 위 주소로 다시 게시한다. 다른 대화에서 게시할 때는 위 주소를 `url`로 넘겨야 같은 주소가 유지된다.
