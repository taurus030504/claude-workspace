# claude-workspace

This repository is also an Obsidian vault for a design-content (디자인콘텐츠과) teacher's lesson planning. See `홈.md` for the folder map.

When writing notes here:
- Write notes in Korean, as Markdown with YAML frontmatter, following the matching template in `90_템플릿/`. Replace `{{date}}` with today's date and `{{title}}` with the note title.
- Put each note in its folder: lesson plans → `10_수업설계`, idea brainstorms → `20_아이디어뱅크`, rubrics → `30_수행평가`, software tips → `40_소프트웨어_활용`, unsorted → `00_Inbox`.
- Link related notes with `[[wikilinks]]` (file name without `.md`).
- Do not edit `.obsidian/workspace*.json`; they are per-device and gitignored.
