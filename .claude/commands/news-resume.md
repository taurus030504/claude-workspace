문영일보 기사 사이트 작업을 이어서 한다. 아래 순서대로 준비한 뒤 교사에게 짧게 보고한다.

1. `news-article/작업노트.md` 를 처음부터 끝까지 읽는다. 여기 적힌 결정은 이미 교사와 합의된 것이므로 다시 묻지 않는다.
2. `anthropic-skills:웹앱-빌드` 스킬을 불러 규칙을 확인한다.
3. `news-article/index.html` 에서 `<script type="application/json" id="site-data">` 블록을 읽어
   현재 기사·기자·댓글 수가 작업노트와 맞는지 확인한다. 다르면 작업노트를 고친다.
4. `git log --oneline -8` 로 최근 작업을 확인한다.
5. 교사에게 아래만 보고하고 다음 지시를 기다린다.
   - 지금 상태 한 줄 (기사 몇 편, 화면 몇 개, 공유 링크)
   - 작업노트 5장 "아직 답을 못 받은 것" 중 다음 작업을 막고 있는 것 2~3개
   - 바로 할 수 있는 다음 작업 제안 1~2개

작업 중 지킬 것:
- 동료 교사로서 제안·검토한다. 시나리오 문안은 지어내지 않고, 교사가 요청한 초안만 쓰며 초안임을 밝힌다.
- 큰 수정 전 `index_v번호.html` 백업, 수정 후 Playwright로 실제 동작 확인, 커밋·푸시.
- 결정이 새로 생기면 작업노트를 같이 고친다.
- 공유 링크 업데이트는 `/news-publish`.
