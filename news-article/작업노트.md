# 문영일보 기사 사이트 작업노트 (새 세션 인수인계용)

새 세션은 이 파일을 먼저 끝까지 읽고 시작한다. `/news-resume` 명령이 이 일을 대신 한다.
마지막 갱신: 2026-10-05 (저녁, 세션 2)

---

## 1. 무엇을 만들고 있나

- 특성화고 디자인콘텐츠과 수업용 **소문·가짜뉴스 추적 학습 게임**의 한 부품.
  최종적으로는 **하나의 게임 웹앱(단일 HTML)** 에 합친다.
- 이 폴더(`news-article/`)는 게임의 8종 자료 템플릿 중 **"포털 뉴스"** 견본이다.
  나머지 7종: 사진 SNS · 짧은 글 SNS · 메신저 · 영상 · AI 답변 · 공식 공지 · 커뮤니티 (아직 없음).
- 사용자(교사)는 기획자이자 디자인 교사다. 대신 기획하지 말고 **동료 교사로서 제안·검토**한다
  (아이디어는 5개 이상 서로 다르게 발산 → 비교 → 추천. 동의만 하지 말고 문제점을 짚는다).

## 2. 지켜야 할 규칙 (웹앱-빌드 스킬 + 이번 대화에서 정한 것)

- 시나리오·카드·자료실·인물 문안을 **지어내지 않는다.** 모르는 칸은 `"[교사 입력]"`(화면에 노란 표시).
  단, 교사가 요청한 초안(기사·댓글)은 써도 되며 **초안임을 알리고** 고칠 수 있게 데이터에만 둔다.
- 실제 서비스명·로고·고유 아이콘·브랜드 색 조합 금지 (공유 버튼은 일반 아이콘, 메신저 캡처는 카톡 색 아님).
- **인물 얼굴 사진 금지** → 일러스트·실루엣만 (기자 프로필은 SVG 일러스트, 넥타이 없음: 성별 미정).
- 생성형 AI 호출·채팅 기능 없음. 외부 API는 나중에 파이어베이스뿐(키는 파일에 넣지 않음).
- 데이터는 HTML 안 `<script type="application/json" id="site-data">` 한 곳.
- 큰 수정 전에는 `index_v번호.html` 로 이전 판을 남긴다 (현재 v1~v8 있음).
- 환경: 1인 1PC, 소리 없음(알림은 색·배지), 학생 문해력 약함(화면 글 최소, 큰 버튼).
- 화면 명칭: 분석관·수사관·당사자·네티즌. 추리 예능 용어 쓰지 않음.

## 3. 확정된 결정

| 항목 | 결정 |
|---|---|
| 매체 | **문영일보** (가상). 로고 `assets/문영일보_로고_v2.webp`(괄호 없는 판), HTML에 data URI로 내장. 강조색 `#ed1653` |
| 참고 디자인 | newsclaim.co.kr 기사면 구성만 참고 (로고 가운데 헤더, 3단 본문). 그 매체를 흉내 내지 않음 |
| 기자 | **한지원 기자** (가상). 부서 "연예부"(내가 기사 분류를 보고 넣은 값), 이메일·소개는 `[교사 입력]` |
| 화면 | 기사(`#article-아이디`) · 기자 프로필(`#reporter-hanjiwon`) · 전체기사(`#list`) · **댓글 작성자 목록(`#users`) · 작성자별 댓글(`#user-닉네임`)** · 교사 테스트용 초기화(`#reset`) |
| 시작 화면 | 처음 열면 **학번이름 + 닉네임** 입력. 학번이름은 실제 로그인창처럼 **`1401강기범` 한 칸**(숫자 4~5자리+한글 2~5자, 띄어쓰기는 지움). 닉네임은 바꿀 수 없음. 학번이름은 화면에 안 보임 |
| 실명 글 | **실명 = 닉네임**. 네티즌의 "실명 글 무제한"은 닉네임 댓글 |
| 익명 | **사이트 전체 1회**. 댓글창에는 익명 체크만 있음 → 동의 팝업 후 등록 → "익명 사용 완료". 지워도 기회 복구 안 됨 |
| 댓글 기능 | 추천·반대(토글, 둘 중 하나, 내 댓글엔 불가), BEST(추천 50↑ 상위 3개, 정렬과 무관하게 **맨 위 고정**), 최신순/추천순, 10개씩 + 더보기, 내 댓글 2단계 삭제 |
| 기사 반응 | 기사별 추천·반대(토글). 시작 수치는 데이터 `"반응"` |
| 저장 | 지금은 **각자 브라우저(localStorage)** 에만. 코드의 `store` 객체 get/set만 바꾸면 실시간 저장소로 교체 가능 |
| 댓글 추적 | 댓글의 닉네임을 누르면 그 사람이 **모든 기사에 쓴 댓글 + 추천·반대 수**를 기사별로 봄(`#user-닉네임`). 댓글창 머리의 "작성자별 보기"는 전체 작성자 표(`#users`, 댓글·기사·추천·반대·마지막 댓글). 익명 댓글은 추적 안 됨. 내 댓글도 포함 |
| a1 제목 어조 | **의문형·추측형 금지, 단정하는 제목**("기자는 악의를 갖고 썼다"). 현재: 이은호·김서진, SNS 스토리에 '비밀 연애' 메시지 캡처 공개…"나 말고 딴 사람 생겼어?" (제목·부제는 내 초안, 본문은 교사 원고 그대로) |
| a1 사진 | **교사가 만든 메신저 화면 캡처(`assets/a1_단톡방캡처.webp`, 713×2000)를 그대로 내장**(종류 `"사진"`, 10-05). 이전 CSS 스토리 데이터는 `"이미지(이전)"`에 보관. 바꿀 때는 `python3 tools/embed_image.py a1 <파일> "<설명>"`. 캡처 속 대화방 이름 "한문예고 모지리들 5", 이은호 표시명 "으노", 캡처에는 기사 뒤 대화(김서진 "또 헛소리 하면 너랑 안 놈", 최이서 "[속보] 이은호와 김서진…사귀자마자 결별해…" 등)까지 들어 있음 |
| C씨 | 본문의 "C씨" = 캡처 속 **최이서**(스토리를 올린 동창, 캡처의 "나")를 기사에서 가명 처리한 것 |
| 댓글 문체 | AI 티 금지: 맞춤법 틀림·줄임말·초성, 한 단어 반응, 딴소리, "베댓" 같은 참조, 기사 직후에 몰린 시각, 추천은 소수에 몰리고 대부분 0~10 |

### 이은호·김서진과 무관한 한지원 기사 (10-05 추가, 전부 내 초안 · 가상 인물·작품)
"한 커플 전담 기자"로 보이지 않게 하는 완충재이자, `기자_행동패턴.md`의 패턴을 하나씩 심어 둔 기사. 추천·댓글 수는 a1·a2보다 낮게 잡아 "많이 본 기사" 순위를 바꾸지 않음.

| 아이디 | 날짜 | 심은 패턴 | 기사 | 댓글 / 특징 |
|---|---|---|---|---|
| a4 | 09.17 | 6 소속사 "확인 중"·후속 없음, '[단독]' 남발, 익명 "관계자" | [단독] 송하람, '밤의 서재' 캐스팅…소속사 "확인 중" (이미지 없음) | 9 / "뭐만하면 단독" 류 냉소 |
| a5 | 09.20 | 정상 기사(보도자료 받아쓰기, 문제 없음) — 챗지피티 A안 | 윤태오, 8개월 만에 신곡 '도화선' 컴백 (이미지 종류 `포스터`) | 8 / 팬 반응, BEST 없음 |

| a7 | 10.01 | 9 커뮤니티 반응 모음(본문이 댓글 나열) | '여름의 끝' 결말 두고 갑론을박 (방송 캡처) | 12 / nightowl "기사가 댓글 모음집이네" |

- 챗지피티 B안(같은 모자)은 후반 단서와 겹칠 수 있어 **넣지 않음**.
- 새 인물(송하람·윤태오·강유나·서민재)·작품('밤의 서재'·'도화선'·'여름의 끝')이 시나리오 인물 12명·실제 연예인과 겹치는지 **교사 확인 필요**.
- 아직 안 심은 패턴: 10 속도(a1 다음 날 1~2시간 간격 후속 기사), 8 제목 장사. 교사가 원하면 a1 후속 "양측 소속사 '확인 중'" 기사(a1-2)로 한 번에 해결.

- a1 본문: 교사가 10-05에 준 2차 원고(4문단, "C씨" 등장, "생겼어?"로 오타 수정)를 **실제 받아쓰기 기사 문체로 고증**해 7문단으로 늘렸다. 교사 문장은 거의 그대로 두고, 앞에 한 줄 리드("열애설에 휩싸였다"), 뒤에 누리꾼 반응·"한편" 예능 연결·"소속사 입장 없음" 문단을 붙였다(이 세 문단은 내 초안). 스토리 글은 "둘이서 비밀 연애를 한다", 캡처 대사도 "생겼어?"로 맞춤. 댓글 속 "생겻ㅅ어"는 네티즌이 옮겨 친 것으로 보고 그대로 둠.
- "C씨" = 최이서(교사 확인, 10-05). 댓글 속 "생겻ㅅ어"도 교사 지시로 "생겼어"로 고침(캡처 원문은 "생겻ㅅ어"지만 기사·댓글은 바른 표기로 통일).
- a2·a3 본문과 모든 댓글은 **내가 쓴 초안**. 예능 이름 '동창회 가는 길'도 임시값.
- 같은 닉네임이 기사마다 태도를 바꾼다: hoonnn(친해보이네 → 사귀는거 아님?ㅋㅋ → 걍 사귀는거 아님?),
  은호만바라봐, 연두빛, 서진이꽃길만, 포카칩조아, nightowl 등.
- 사이드바 "많이 본 기사"는 데이터 기사를 추천+댓글 순으로, 나머지는 시나리오와 무관한 가짜 제목.

## 5. 아직 교사에게 답을 못 받은 것

1. 이은호·김서진 **직업**(배우/아이돌/가수 등) → 지금 기사엔 직업 표기를 일부러 뺐다.
2. **예능 프로그램** 이름·형식 확정('동창회 가는 길'은 임시).
3. a2·a3 **날짜가 시나리오 타임라인과 맞는지** → 맞춘 뒤 `정합성-검사` 스킬로 점검.
4. 예능 속 **이은호 말투(ㅔㅔㅔ)를 단서로 쓸지** (정답지·분석관 카드와 연결되는 문제. 지금 a2 밈은 말투가 아니라 "또 너야?").
5. 한지원 기자 **성향**(믿을 만한 기자 vs 받아쓰기 기자) → 과거 '캡처 받아쓰기 + 정정보도' 기사를 넣을지.
6. 각 기사의 **공개 턴** (`"공개 턴": "[교사 입력]"`).
7. **학번이름 저장 위치**: 스킬 규칙은 "실시간 모드는 좌석 번호만, 이름 저장 안 함". 교사는 학번이름 입력을 원함.
   지금은 브라우저에만 저장. 실시간 모드(파이어베이스) 때 서버에 올릴지 교사 결정 필요.
8. 그밖의 이전 기사 후보(지난 대화에서 제안): 예능 발언 왜곡, 제작진 비하인드, 제목 수정 이력 기사, 커뮤니티 반응 모음 기사, 여론 추이 인포그래픽.
9. ~~카카오톡 화면 캡처 파일~~ → 10-05 받아서 넣음.
10. ~~챗지피티 추가 기사 3안~~ → 10-05 교사 지시("관련 없는 기사 몇 개 만들어 둬")로 A·C + 내 2편(a4·a7)을 넣음. B는 뺌. 이로써 5번(기자 성향)은 사실상 "받아쓰기 습관 있는 기자"로 감. 교사가 검토 후 빼거나 고칠 수 있음.
11. 날짜는 "대충 맞춰 두고" 진행하라고 함(2026-10-05). 정밀 대조는 나중에 `정합성-검사`.

## 6. 파일

```
news-article/
  index.html              ← 원본(게임에 합칠 파일). 단일 파일, 로고 내장
  index_v1~v6.html        ← 이전 판
  assets/                 ← 로고 원본(png=첫 판, webp=현재), a1_단톡방캡처.webp(교사 제작, a1에 내장됨)
  tools/build_artifact.py ← 공유 링크용 사본 만들기
  tools/embed_image.py    ← 교사 이미지 파일을 기사 이미지("사진")로 내장
  기자_행동패턴.md         ← 받아쓰기 기자 행동 패턴 10가지 + 한지원 기사 배치 계획(설계 근거)
  작업노트.md              ← 이 파일
.claude/commands/news-resume.md   ← 새 세션 시작 명령
.claude/commands/news-publish.md  ← 공유 링크 업데이트 명령
```

```
               | { 종류:"스토리 캡처", 스토리 글, 대화방 인원, 대화[{보낸 사람, 말[]}], 태그[], 설명 }
               | { 종류:"방송 캡처", 프로그램, 자막, 설명 },
  공개 턴, 반응:{추천, 반대}, 댓글:[ {닉네임, 시각, 내용, 추천, 반대} ]
} ]
```
새 이미지 종류는 코드의 `RENDER_IMAGE` 에 함수 하나를 추가한다.
